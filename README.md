Full-Stack Skills

Explanation:
This project demonstrates Full-Stack capabilities by combining a React frontend with a backend implementation.
1. Frontend: The project features a React application (`EliteAdventureReact`) with component-based architecture and React Router.
2. Backend: It includes a custom Node.js server (`server.js`) that handles API requests (`GET` and `POST` to `/api/inquiries`) and manages data persistence using a JSON file system.
3. Integration: The frontend and backend are integrated (referenced by the proxy setting in `package.json`), enabling end-to-end data flow from the UI to the server.
